# /ship — Commit with User Verification

Prerequisites: /validate PASSED + /qa user CONFIRMED (have their exact message ready).

STEP 1: Final sanity checks
git diff --stat (review scope of changes)
pnpm tsc --noEmit && pnpm eslint . --max-warnings 0

STEP 2: Stage changes interactively
git add -p
Review every hunk. Do NOT blindly git add . — understand every change you're committing.

STEP 3: Write commit message using this EXACT format:
```
type(scope): [JRNOS-XXX] short description (max 72 chars)

[2-3 sentences from engineering plan: what this implements and why it matters]

Automated tests: N passing
User verified: [PASTE THE USER'S EXACT CONFIRMATION MESSAGE HERE]

Closes #[issue number if exists]
```

CRITICAL — NEVER include in any commit message:
- "Co-authored-by: Claude" or any variant ← hard blocked by commitlint
- "Generated by Claude Code" ← hard blocked by commitlint
- "AI-assisted" or "🤖" ← hard blocked by commitlint
Just clean, professional commit message. The user's words are the only attribution that matters.

Allowed types: feat / fix / chore / docs / test / refactor / perf
Allowed scopes: p1 p2 p3 bkt irt rag db neo4j auth admin seed ai embeddings ui exam mastery canon infra

STEP 4: Commit and push
git commit -m "[message from step 3]"
git push origin [current-branch-name]

STEP 5: Open PR
gh pr create \
  --title "[same as commit first line]" \
  --body "$(cat .context/epics/EXX/EXX-SXX.md | head -60)" \
  --base develop

Output the PR URL. Done.
